# Limitations and outstanding work
- Only synthetic data have been run. Historical 2005–2025 study, historical stress windows and empirical findings are blocked by absent permissioned inputs. No data provider or employer review has been approved.
- Selected universe, lookbacks, calendar proxy, snapshot vintage, daily-close execution and a flat illustrative spread/cost assumption are modelling choices. They are not validated live execution. No leverage, borrowing, market impact, tax, fund flows or external management fee.
- Sample covariance is noisy and can lag shocks. Risk reference is not a promised ceiling. Synthetic designed regimes do not represent a fitted joint asset-return distribution.
- Rate adapter rejects negative values, fixes ACT/360 and uses a bounded availability-date rule. Real publication metadata must be prepared externally. A current snapshot cannot reconstruct revisions or actual information sets without archival data.
- The scalar reference independently checks the ledger using supplied targets. It does not independently rebuild the full data calendar and strategy signals. Reconciliation tolerances are absolute index points and suited to this scale, not arbitrary enormous portfolios.
- Replay requires an unchanged full input prefix, including prices needed for rolling decisions. It is a saved holdings-state workflow, not an optimized streaming feed or enterprise event system. Computed decisions are rebuilt from validated history; only the remaining ledger is advanced.
- Versioned results preserve local snapshots. The illustrative correction is a synthetic one-day price revision, not a corporate-action operations platform. No published data were changed.
- Option model assumes a non-distributing lognormal surrogate, constant volatility and rate; index control does not justify that distribution. There are no actual quotes, implied-vol calibration, stochastic-volatility or exotic claims. Greeks at nonsmooth limits are N/A. Extreme finite input overflow and broad numerical conditioning are not production-hardened.
- No exchange tick rounding, trading-halt feed, timezone intraday execution engine, bid/ask order simulator, provider integration, QuantLib external oracle, or real browser accessibility audit across assistive technologies. No live operations, cloud deployment or human approval claimed.
- AI assisted code, documentation and test generation. Numeric results come from deterministic Python. Automated tests cannot replace financial review or the owner's ability to explain the work.
